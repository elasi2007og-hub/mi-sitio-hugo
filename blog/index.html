    Publicando nuestro sitio Hugo en GitHub Pages

    En esta práctica desplegamos nuestro sitio estático de Hugo en Internet a través de GitHub Pages siguiendo la filosofía KISS: Configuramos baseURL = "https://elasi2007og-hub.github.io/mi-sitio-hugo/" y publishDir = "." en hugo.toml para generar el HTML plano directamente en la raíz del repositorio. Añadimos static/.nojekyll para evitar que GitHub procese el repositorio con Jekyll. Utilizamos la función relURL de Hugo en layouts/partials/header.html para que la hoja de estilos (css/estilo.css) y el menú de navegación resuelvan correctamente bajo la subruta /mi-sitio-hugo/.     Despliegue de sitios estáticos con Hugo en IAW

    En esta entrada repasamos las ventajas de utilizar un generador de sitios estáticos como Hugo en el módulo de Implantación de Aplicaciones Web (IAW): Velocidad y seguridad: al compilar a HTML y CSS puros, no requiere base de datos ni ejecución de código dinámico en el servidor. Plantillas modulares: gracias a los parciales (layouts/partials/header.html y footer.html), mantenemos una cabecera y pie de página consistentes en todas las secciones.
